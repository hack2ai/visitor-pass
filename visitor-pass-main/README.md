
# AI Visitor Pass Management System

A modern AI-powered Visitor Management System built using React, Node.js, PostgreSQL, Prisma, QR Codes, OCR, Face Recognition, and OpenAI.

## Tech Stack

- React + TypeScript
- Express + TypeScript
- PostgreSQL
- Prisma
- Tailwind CSS
- shadcn/ui
- JWT Authentication
- QR Code
- Docker
