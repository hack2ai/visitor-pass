## Overview

The AI Visitor Pass Management System is a modern full-stack web application for managing visitors in an organization.

The platform provides a centralized workflow for registering visitors, managing approval status, generating/verifying visitor passes, monitoring visitor activity, and viewing administrative statistics.

## Key Features

- User authentication and protected routes
- Role-based administrative access
- Visitor registration and management
- Visitor approval and rejection workflow
- Visitor status tracking
- QR-based visitor verification
- Administrative dashboard
- Visitor statistics and analytics
- Recent visitor activity
- Reports and filtering
- Profile management
- Application settings
- REST API architecture
- PostgreSQL database
- Prisma ORM
- Responsive frontend
- Type-safe TypeScript implementation
